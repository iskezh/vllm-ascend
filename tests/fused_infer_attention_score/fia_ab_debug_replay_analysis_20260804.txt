四、结论
--------
1. 离线环境下 custom 与 baseline 的 host tiling (FD 判定/切分/workspace)
   与 kernel 行为 (每核范围、主循环迭代、split 部分结果、LSE 合并)
   全部一致, 输出 bit-identical。算子代码路径本身无差异。
2. 结合四方对比 (fia_online_offline_compare.txt):
   online_base == offline_base (输入保真) 且 offline_custom == offline_base,
   但 online_custom 发散 (285/10240 bitdiff, 逐 token 递增 t1=3.8e-6 →
   t9=0.529, head3 最严重) => 发散只可能来自线上运行环境差异
   (如 block_table 张量分配外的邻居内存内容), 而非算子逻辑或输入。
3. 下一步建议: 毒化尾部行实验 (在 oversize block_table 分配的 10..13 行
   植入合法 block id), 验证 custom 是否存在越界读 block_table 的行为。
